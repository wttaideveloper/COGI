## Make a PDF
1. Double-click `COGI-Homepage-Image-Options.html`
2. Press **Ctrl+P**
3. Choose **Save as PDF**
4. Send that PDF + the JPG folder to the client

## Live site preview
Same images are copied to:

`public-website/public/samples/homepage/`

URLs (with public site running):

- http://localhost:5173/samples/homepage/01-clinic-team.jpg
- http://localhost:5173/samples/homepage/02-care-hands.jpg
- …etc.

In Admin → Homepage Manager, paste those URLs as slides, or upload the JPGs from this folder.
