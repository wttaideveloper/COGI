# Admin User Guide

## Login

1. Open https://admin.coginternational.org (local: http://localhost:5174).
2. Sign in with your COGI admin email and password.
3. Demo (local only): `admin@cogi.local` / `admin123`.

## Change homepage content

1. Open **Homepage** in the sidebar.
2. Toggle section visibility or drag to reorder.
3. Edit hero slides, mission, methods, impact stats.
4. Save draft → **Preview** → **Publish**.

## Edit a page

1. **Pages** → select or create.
2. Set title, slug, SEO fields.
3. Add/reorder sections in the page builder.
4. Save draft or publish.

## Upload an image

1. **Media** → Upload.
2. Add alt text and caption.
3. Copy URL or select from pickers in content forms.

## Manage menus

1. **Navigation** → Header or Footer menu.
2. Add items, nest dropdowns, set order and open-in-new-tab.
3. Save. Public site picks up published navigation without redeploy.

## Add news / blog

1. **Blog** → New article.
2. Title, summary, TipTap body, featured image, category, tags.
3. Publish when ready.

## Add events

1. **Events** → New.
2. Dates, venue, registration link, featured image.
3. Mark featured for homepage calendar teaser.

## Team members

1. **Team** → Add board or global member.
2. Region/country for global team; hide sensitive contact if needed.

## Publications & partners

Use **Partners** and related modules to upload logos and links.

## Preview & publish

Use **Preview** to open the public site with a preview token. Drafts are not public until published.

## Enquiries & newsletter

- **Enquiries**: filter by status, add notes, export CSV.
- **Newsletter**: view subscribers, export CSV.

## Reset password

Login page → Forgot password → follow email link (configured SMTP/Resend in Strapi).
